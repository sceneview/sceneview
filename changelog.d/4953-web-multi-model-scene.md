- **SceneView Web loads a whole scene on a phone budget.** The script-tag viewer gains `addModel()`, which adds a model next to the others and returns a handle you can move, animate and remove, and `loadScene()`, which loads a set in the order a visitor sees it: the environment and the primary model first, the rest once the canvas is on screen and the page is idle, without blocking the first paint, and stopping when the visitor leaves. `deviceTier()` sorts the device into low, mid or high and caps the download, the triangles, the texture size and the pixel ratio for it. Each entry can name a lighter file per tier and size hints, so an entry over budget is skipped before it downloads. The `scene-lab.html` test page measures it all (#4953).
