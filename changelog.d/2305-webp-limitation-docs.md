- **WebP-textured glTF models — documented the Android/upstream limitation more prominently ([#2305](https://github.com/sceneview/sceneview/issues/2305)).** `docs/docs/nodes.md`'s "Common mistakes" table now has a direct entry for `EXT_texture_webp` glTF textures (Logcat `Missing texture provider for image/webp`, renders untextured), linking to the existing full writeup in `docs/docs/troubleshooting.md` and the workaround (re-encode to PNG/JPEG/KTX2). Re-verified upstream as of Filament `v1.73.0` (2026-07-07, current latest release, newer than the pinned `1.71.5`): `FILAMENT_SUPPORTS_WEBP_TEXTURES` still defaults `OFF` in `android/gltfio-android/CMakeLists.txt`, so the published Android `gltfio-android` AAR still ships with `isWebpSupported() == false` and no `image/webp` provider — no released Filament version has flipped this on. No SceneView code change; no Filament version bump.
