- **iOS: `SceneReconstructionNode.enableReconstruction` no longer replaces the AR session or shows a debug overlay.** It used to run a brand-new `ARWorldTrackingConfiguration`, dropping the host's frame semantics (people occlusion, person segmentation), detection images and plane settings, and it switched RealityKit's `.showSceneUnderstanding` wireframe on in the app's view. It now amends the running configuration (no `.resetTracking`, no `.removeExistingAnchors`), leaves face/body-tracking sessions untouched, returns whether the mesh is on, and draws the wireframe only when the caller passes `showDebugMeshOverlay: true` (**behaviour change** for callers that relied on the implicit overlay). The iOS depth-collider demo now actually turns the LiDAR mesh on before enabling mesh physics.
