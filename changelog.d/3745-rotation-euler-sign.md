- **`Node.worldRotation` reads the same Euler angles as `Node.rotation` ([#3745](https://github.com/sceneview/sceneview/issues/3745)).** A node with no parent set to `rotation = Rotation(y = 30f)` read `worldRotation.y == -30f`: the `worldRotation` getter returned kotlin-math's `Mat4.rotation` (YXZ, yaw sign negated) while `rotation` and both setters are ZYX, so `node.worldRotation = node.worldRotation` turned any node that had yaw — by 64° for `(20, 30, 15)`. The getter now reads `worldQuaternion.toEulerAngles()`. **Behaviour change for code that reads `worldRotation`:** the Y sign flips back, compound rotations read different numbers, and Y now stays within ±90° (a 120° yaw reads `(180, 60, 180)`), as `rotation` always has. `rotation`, `worldQuaternion`, the setters and rendering are unchanged. See the migration guide.
