- **iOS demo app: usage analytics, crash reports and push notifications, with a switch for each ([#4243](https://github.com/sceneview/sceneview/pull/4243)).** SceneView Demo on iOS now uses Firebase Analytics, Crashlytics and Cloud Messaging. Firebase lives only in `samples/ios-demo`; SceneViewSwift still has no telemetry. Analytics never reads the advertising identifier and the app does not ask for tracking permission. The privacy manifest declares no tracking, and ad consent is denied. A new Privacy section in About turns usage and crash reporting off, which also clears pending analytics data and resets the app instance ID. The same section turns notifications off, which unsubscribes from every topic and deletes the push token. Notifications are only offered after the second return to Home. "Not now" waits seven days and the offer comes back at most three times. Tapping a notification opens the sample it names, even when the app was not running; an unknown sample opens Home. Builds without `GoogleService-Info.plist`, which is never committed, run without Firebase and cannot crash on it.
