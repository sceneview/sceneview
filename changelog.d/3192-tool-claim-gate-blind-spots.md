- **The MCP tool-claim gate had three structural blind spots, and they are why the false claims above survived a gate that reported OK ([#3192](https://github.com/sceneview/sceneview/issues/3192)).** It now scans **155 files, up from 115**, and still passes.
  - **`.json` was not in `SCAN_EXT`.** `docs/docs/structured-data.json` sat inside the already-scanned `docs/docs` directory and was skipped purely on its extension, while advertising a tool that the gate's own source comment described as removed. The directory was never the gap.
  - **`marketing/` and `mcp/src/` were outside `SCAN_DIRS`.** `mcp/src/` returns whole Markdown documents to the model — a gate that reads the docs but not the strings the server *answers with* is checking the smaller half. `.ts` joins `SCAN_EXT` with it.
  - **Tool names were matched by pairing backticks per line.** `website-static/playground.html` held a copy-to-clipboard prompt as one JS template literal containing a ``` fence; on that single line the backticks paired off shifted by one and every fabricated name landed in a gap between pairs. Two occurrences shipped, one was fixed by hand and reported as the fix, and the second survived because the gate that was meant to catch it structurally could not. Names are now matched as bare tokens — `TOOL_SHAPE` is a closed verb list and every legitimate hit is in the registry by construction, so the code-span requirement bought no precision and cost a real miss.
- **The widening surfaced 14 findings, all diagnosed rather than allowlisted away.** `view_in_ar` (the Material Symbols ligature, in 7 icon elements) and `search_term_string` (a schema.org `SearchAction` literal) join `NOT_A_TOOL` with their reasons. `*.test.ts` files are now skipped, because they deliberately construct names like `get_nonexistent_guide` to assert the production code rejects them — without that narrowing the gate would report its own passing test suite as violations of itself.
- **Four self-test cases added, one per closed blind spot, all mutation-verified**: removing `.json` from `SCAN_EXT`, removing `mcp/src` from `SCAN_DIRS`, removing `.ts` from `SCAN_EXT`, restoring the backtick pairing, and removing the test-file filter each turn exactly the owning case red. The regression fixture is asserted to be exactly one line, since the scan is per-line and a fence split across lines would desynchronise nothing and assert nothing.
