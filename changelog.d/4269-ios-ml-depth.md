- **SceneViewSwift**: monocular ML depth for iPhones without LiDAR. `ARSceneView(...).depthSource(.ml(estimator))` (or `.auto(ml:)`, LiDAR first) turns the camera image into a metric `ARDepthFrame` with `source == .ml` at up to 5 Hz by default (Android's `targetHz`) off the main thread: the relative depth is scaled to metres with a robust fit `1/z = s·d + t` against ARKit's feature points and plane raycasts (consensus seed, Huber IRLS, outlier rejection), smoothed over time, held for a few frames when anchors drop out, run at half rate at a serious thermal state and paused at a critical one (as Android: only SEVERE pauses), and paused while tracking is lost. `.onDepthFrame` and `.onDepthSourceState` report frames and status. The states use Android's `MlDepthState` names — `preparing`, `waitingForAnchors(anchors:)`, `running(MLDepthStats)`, `throttled`, `failed(error)` — and `MLDepthStats` carries the same figures as `MlDepthStats` (last and median inference time over 30 estimates, published Hz, anchors, inliers, RMS relative error, holding). `ARDepthFrame.Source` has the same cases as Android's `ArDepthFrame.Source` (`.native` / `.ml`). One estimator instance is only ever called from one serial queue, even when a view swaps its depth source mid-estimate.
- **SceneViewDepthML** (new, separate product): `DepthAnythingV2Estimator` runs Depth Anything V2 **Small** (Apache-2.0, Apple's Core ML conversion, 8-bit weights) on the Neural Engine. The package bundles no model: `DepthModelStore` downloads it once from a pinned revision with SHA-256 checks (25.4 MB, against 27.7 MB for Android's int8 model), compiles it and swaps it into a cache keyed by name and revision; concurrent requests share one download, each fetch stages in its own folder, leftovers older than 10 minutes are swept, and a cached model that no longer loads is purged and fetched again once. It also takes an app bundle resource or an On-Demand Resources tag. Base and Large are not supported (non-commercial licence). Tested offline with a stub URL protocol and a tiny hand-built Core ML model.
- **iOS demo**: new **Depth Visualization** screen — false-colour depth over the camera with a Camera-to-Depth blend, a LiDAR / ML source pill and an ML card (download, preparing, waiting for surfaces, cost per estimate, holding, thermal pause, failure), mirroring Android. ML mode leaves ARKit's `.sceneDepth` off.
