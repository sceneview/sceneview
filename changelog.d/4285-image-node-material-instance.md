- **Android: removing an `ImageNode`, `BillboardNode` or `TextNode` from a live scene no longer aborts the app ([#4285](https://github.com/sceneview/sceneview/issues/4285)).** `destroy()` passed `MaterialLoader` a new wrapper of its material instance, which the loader did not recognise, so the instance was never destroyed. A few frames later its texture was freed and Filament aborted with `Invalid texture still bound to MaterialInstance`. This was the ML Object Label crash on the 7th label. Each removed node also leaked one material instance. The node now destroys the instance the loader created, before its texture, and `MaterialLoader.destroyMaterialInstance` accepts any wrapper of a tracked instance, such as `node.materialInstance`.
