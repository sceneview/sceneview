- **`worldQuaternion` / `worldRotation` writes no longer run a polar decomposition ([#2267](https://github.com/sceneview/sceneview/issues/2267)).** `worldToLocalQuaternion` / `localToWorldQuaternion` (and the Euler `worldToLocalRotation` / `localToWorldRotation` variants) gained direct-`Quaternion` overloads that compose quaternions directly (`inverse(parentWorldQ) * worldQ`) instead of extracting a quaternion from a 4×4 matrix every call. `Node.getLocalQuaternion` / `getWorldQuaternion` — and therefore the `worldQuaternion` / `worldRotation` setters — now feed the parent's cached world quaternion through these overloads, eliminating the per-write `Mat4` polar decomposition. Behaviour is identical; the legacy `Transform`-based overloads are kept. Part of the hot-path allocation audit ([#2263](https://github.com/sceneview/sceneview/issues/2263)).
