- **Scripts: `worktree-auto-prune.sh` aborts on stale `origin/main` instead of silently deleting unmerged work.** Previously a failed `git fetch origin main` only printed a warning and continued with whatever local `origin/main` happened to be cached — a worktree on a local-only branch with commits past main could then be misclassified as `ahead=0` and removed. The fetch now exits 1 by default; pass `--allow-stale` to opt back into the old offline behaviour. New `--check-active-sessions` flag adds a second guard: a worktree whose path appears in any running `claude*` process command line is skipped (heuristic, opt-in).
