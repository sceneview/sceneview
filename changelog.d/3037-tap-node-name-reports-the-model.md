- **A tap on a model now reports the model on iOS, not a mesh inside it ([#3037](https://github.com/sceneview/sceneview/pull/3037)).** Tapping `black_dragon.usdz` in the Flutter demo on an iOS 26 simulator reported `skin0` — the name of an internal mesh — while the same tap on Android reports `black_dragon`. `SpatialTapGesture` hands back the deepest hit entity, and the Flutter bridge's `flutterTappedNodeName` walked up to the first *named* ancestor; USDZ assets name their meshes, so the walk stopped inside the asset and never reached the model root the bridge itself had named. Android cannot reproduce it: the only collider a loaded model owns is the `ModelNode` root (glTF child renderables get no collision shape), so its hit-test can only ever resolve to the model. The walk now climbs to the model root — the direct child of the bridge's content root, the one entity the bridge names — and reports its file base name without extension, which is what the doc comment already claimed. The React Native iOS bridge had the same bug in a blunter form (it reported `hit.entity.name` raw, with no walk at all) and is fixed the same way; its Android side, which reported `nodeName: null` for *every* model tap because nothing ever named the `ModelNode`, now names each model after its file so both platforms emit the identical string.
- **`nodeName` no longer leaks a URL's query string.** A model source may be a URL (`ModelLoader` loads `https://` on Android), and cutting at the last `.` only strips the extension when it is the last dot in the whole string — `https://cdn/robot.glb?sig=SIG&v=1.2` derived `robot.glb?sig=SIG&v=1`, putting a CDN signature into a payload apps routinely show in a label or send to analytics. Query and fragment are now stripped first, identically on both platforms.
- The payload's world position is the tapped model's, matching Android's `node.worldPosition`. Note the RN Android bridge is still compiled by no CI job — the Kotlin here is checked against the published `v4.7.0` source only; closing that gap is tracked separately.
