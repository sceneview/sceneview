- **`Node.onMove(detector, e, worldPosition)` and `Node.onScale(detector, e, scaleFactor)` overrides now actually run during a gesture ([#3739](https://github.com/sceneview/sceneview/issues/3739)).** Both are documented, `open` extension points meant for subclasses to intercept and clamp a drag or pinch — but the internal gesture delegate called its own copy of these functions instead of dispatching through the node, so an override was silently skipped on every real touch. `onRotate` was unaffected and is unchanged. The unused, superseded `applyScaleGesture()` helper (`sceneview-core`) is removed along with its tests — scale clamping has lived in `evaluateScaleEdit()` since #3699.
