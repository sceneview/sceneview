- **Real-world size for automatically placed models ([#4820](https://github.com/sceneview/sceneview/pull/4820)).** `AutoPlacementModel` takes a `size: PlacementSize`: `PlacementSize.RealWorld` keeps the asset's authored metres (a 1 m glTF is 1 m, nothing is rescaled) and `PlacementSize.FitInto(meters)` fits the longest authored axis (before `assetRotation`) into that many metres. `AutoPlacementState` now reports the placed model's dimensions in metres — `baseSize` at 100 %, `placedSize` following the pinch, and `isAtRealWorldSize` — so an app can show "1.80 m tall" or let the user pick a size with `scaleTo(target / baseSize.y)`; `scaleTo` clamps to `scaleRange` (25–400 % by default), so widen it for a target outside that range. `ModelNode` gains `worldSize` (width × height × depth in world metres, parent scales included) and `worldBoundingBox` (world-space bounds: floor contact and footprint); like `boundingBox`, both throw `IllegalStateException` once the model is destroyed (#4827). The existing `scaleToUnits` overload and its 0.3 m preview default are unchanged. In the Android demo, a measured file now arrives in AR at its authored size — an STL, OBJ or PLY reopened in another unit goes as the re-converted file — and the "Actual size" read-out shows its height.
