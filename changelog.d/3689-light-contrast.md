- **Website text now reads at 4.5:1 or better in light mode ([#3689](https://github.com/sceneview/sceneview/issues/3689)).** The hero's "Try the demo:" label used a surface token on the blue gradient. It is now white at the hero description's 0.9, which gives 5.5:1 on both gradient stops. "Stable" and "Fully supported" labels use a darker green in light mode (`#166534`), which holds 5.6:1 or better on their tinted chips. `--color-outline` is `#56688f` in light mode, so the playground sidebar headers, counts and line numbers that use it as text pass on every surface tier. Captions and API signatures no longer dim the muted token with `opacity`. Code annotations in the playground are `#b45309`. The "v4" badges in the developer-tools section pointed at an undefined `--accent`, so they rendered white on white; they now use the primary colour. A DOM audit of seven pages found 85 failing text nodes in light mode before this change and 0 after. Dark mode went from 7 to 0.
