- Device-QA: opt-in **Rosetta x86_64 AR rig** — `setup-ar-emulator.sh --rosetta` provisions a separate `Pixel_7a_x86` AVD (Intel emulator bundle + x86_64 system image + the `_x86_for_emulator` ARCore APK) on a reserved port outside the QA emulator pool. It is the only path that can host a **live-camera ARCore session** (tracking, hit-tests, anchors) on an Apple Silicon host, where the default arm64 AVD structurally cannot (#2754). **Not yet proven end-to-end**: no boot has completed on the development host so far — the unaccelerated guest needs the machine to itself and every attempt so far ran into host contention. Disk-gated, every guest probe time-bounded (a wedged guest fails fast with a verdict instead of stalling the wait loop), and the run self-verifies with the camera-topology probe (camera HAL id `0`) (#2758)
