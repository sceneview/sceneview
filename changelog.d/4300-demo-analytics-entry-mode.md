- **Demo apps (Android and iOS): `sample_open` now sends the category as a stable slug (`create`, `view_3d`, `place_ar`, `understand`, `dev_tools`) plus the received `entry_id` and the umbrella card's `mode`; each mode change inside an umbrella card logs `sample_interaction` with `control = "mode_<x>"` ([#4300](https://github.com/sceneview/sceneview/pull/4300)).** A mode opened by a link is reported by `sample_open.mode` instead of an extra `sample_interaction`, and the same card and mode use the same slug on both platforms. Demo-app instrumentation only; the SDKs still ship no telemetry.
