- **Docs: the Android XR snippets compile against the Jetpack XR beta SDK they cite.** `android-xr.md` and `android-xr-emulator.md` now import `SpatialPanel`, `SubspaceModifier` and `LocalSpatialCapabilities` from their real packages. Passthrough uses `preferredPassthroughOpacity`. glTF models load with `GltfModel.create` before being wrapped in `GltfModelEntity.create`, and the model is closed when the composable leaves. `Session.create` is handled as the suspend call it is, returning a `SessionCreateResult`. Taps on `ARSceneView` go through `onGestureListener`. The manifest example declares the real `android.software.xr.api.spatial` feature instead of a non-existent head-tracking one. The phone-ARCore-in-a-panel approach is flagged as untested on a headset, and points headset users to `XrHandNode` / `XrFaceNode`. The `@XrPreviewApi` opt-in message and the XR KDoc no longer quote `1.0.0-alpha14`. `AGENTS.md` defers to `llms.txt` for version numbers instead of repeating them.
