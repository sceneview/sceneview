- **The demo APKs attached to GitHub Releases are now signed with one stable key ([#4255](https://github.com/sceneview/sceneview/pull/4255)).** `sceneview-android-demo.apk` and `sceneview-android-tv-demo.apk` used to be signed with a throwaway key generated by the build machine, a different one for every release, so a newer APK could not install over an older one and Android developer verification could not recognise them. They are now signed with a single SceneView key registered for Android developer verification, so from this release on each new APK installs over the previous one. If you installed an APK from an earlier GitHub Release, uninstall it once before installing this one. These GitHub APKs are debug builds, meant for trying the samples.
