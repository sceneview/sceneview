- **`LargeModelLoadTest` no longer fails on timing or on logd's line collapsing ([#4874](https://github.com/sceneview/sceneview/issues/4874)).** The concurrent-load test asserts what `awaitModelInstance` guarantees for each of two overlapping calls (main-thread, monotonic progress ending at `Textures 1`, distinct models, an idle loader) and logs whether the second load began before the first one's textures were final, instead of failing when a fast runner finished them first. The extension test checks each existing load's warning on its own, after a distinct log line, because API 30's logd collapses identical consecutive lines from one thread into `identical N lines` and the three loads logged the same warning from the same worker.
