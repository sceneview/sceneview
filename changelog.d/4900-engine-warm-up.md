- **`EngineWarmUp` takes the EGL context and gltfio's texture tables out of a 3D screen's first frame ([#4900](https://github.com/sceneview/sceneview/pull/4900)).** Call `EngineWarmUp.start()`, from any thread, a little before a 3D screen (or in `Application.onCreate()` when the first screen is 3D), or list `io.github.sceneview.EngineWarmUpInitializer` under `androidx.startup`'s provider in your manifest. It then loads Filament's native libraries, creates the shared EGL context and builds the Basis Universal tables gltfio's KTX2 loader needs on its own thread, and `rememberEngine()` only makes the prepared context current. On a Pixel 7a, a 3D board's first frame went from 238 to 184 ms (median), with no significant change to time to first frame. It is opt-in: about 80 ms of background CPU and one EGL context per launch that runs it. A context no engine takes within 5 s is released. The `Engine` itself is still built on the main thread, because Filament ties an engine to the thread that creates it.
- **`rememberModelLoader(engine)` no longer builds gltfio's material provider.** `ModelLoader.materialProvider` and `ModelLoader.assetLoader` keep their types and are created by the loader's first model, so a `SceneView {}` that never loads a glTF never pays the tens of milliseconds the ubershader archive takes to decompress. The first read of either property now has to happen on the main thread, like every Filament call: elsewhere it throws an `IllegalStateException`.
