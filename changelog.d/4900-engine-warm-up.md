- **A 3D screen's first frame no longer creates the EGL context or builds gltfio's texture tables ([ber4444/sceneview#1](https://github.com/ber4444/sceneview/pull/1)).** `EngineWarmUp`, started at app startup by an `androidx.startup` initializer merged from SceneView's manifest, loads Filament's native libraries, creates the shared EGL context and builds the Basis Universal tables gltfio's KTX2 loader needs, on its own thread; `rememberEngine()` takes the prepared context and only makes it current. On a Pixel 7a the chess app's first 3D frame went from 238 to 184 ms (median), with no significant change to time to first frame. The `Engine` itself is still built on the main thread, because Filament ties an engine to the thread that creates it. To skip the warm-up, remove the `io.github.sceneview.EngineWarmUpInitializer` meta-data with `tools:node="remove"`; `EngineWarmUp.start()` runs it by hand, from any thread.
- **`rememberModelLoader(engine)` no longer builds gltfio's material provider.** `ModelLoader.materialProvider` and `ModelLoader.assetLoader` keep their types and are created by the loader's first model, so a `SceneView {}` that never loads a glTF never pays the tens of milliseconds the ubershader archive takes to decompress.
