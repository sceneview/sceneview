- **Two repo-hygiene self-tests had been failing on every mawk host and every host without `xxd` ([#3189](https://github.com/sceneview/sceneview/issues/3189)).** `pre-push-check.sh` reported "2 of 41 gate self-test(s) failed" on a clean tree, which is the worst possible state for a gate: red on `main`, so a reader learns to skim past it. `test-ci-gate-observations.sh` extracted `ADVISORY_CHECKS` from `ci-gate.yml` with an awk regex using a POSIX bracket interval (`{10,}`) — Ubuntu's `/usr/bin/awk` is **mawk**, which implements no bracket intervals and offers no flag to enable them (`-W re-interval` is a vacuous option there), so the pattern matched nothing, the extractor exited on its first value line, and the suite hard-failed with "could not extract ADVISORY_CHECKS". Ten literal spaces express the same block-scalar indent and work under mawk, gawk and BSD awk; the extractor now yields the real list (`Coverage`, `Agent review`) and still tracks a change to it. `test-store-preflight.sh` hard-failed with `xxd: command not found` on hosts lacking `xxd` — a missing tool is not a regressed ES256 signer, and `xxd` remains a declared, checked dependency of `store-preflight.sh` that ships on ubuntu-latest — so that case now skips honestly, the same shape as the neighbouring shellcheck assertion. Both suites pass; the hygiene gate is 41/41 for the first time in this branch's history.
