- **The demo screens' "more" (⋮) menu no longer opens away from the button ([#3323](https://github.com/sceneview/sceneview/issues/3323)).** `DemoOverflowMenu` — the shared overflow anchored last in the identity row of every sample screen — was a plain `Box { GlassIconButton(); DropdownMenu() }` with no alignment hint. That button sits flush against the trailing safe-drawing edge on every demo, exactly the layout `DropdownMenu` is known to mis-anchor (AndroidX b/168594123). The anchor `Box` now carries `Modifier.wrapContentSize(Alignment.TopEnd)`, the documented Compose fix, so the menu opens attached to the glass button on all screens.
