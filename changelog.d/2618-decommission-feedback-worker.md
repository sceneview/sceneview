- **Decommission the orphaned `feedback-worker/` Cloudflare Worker ([#2618](https://github.com/sceneview/sceneview/issues/2618)).** Both demo apps migrated to the zero-permission direct-GitHub bug reporter (#2597), leaving the media-upload/Whisper-transcription worker unused. Removed the `feedback-worker/` directory and its `quality-gate.sh` test block, and reworded the Play Store `DATA_SAFETY.md` + `PLAY_STORE_SETUP.md` to declare **no** user-data collection (the on-device reporter only shares via a user-initiated share sheet or a GitHub issue the user submits). The audio/media-feedback capability is intentionally retired; the Cloudflare infra teardown is a maintainer-side action.
