- **Android scenes share one default Filament engine per process ([#5202](https://github.com/sceneview/sceneview/issues/5202)).** `rememberEngine()` now retains its default engine and EGL context between screens, even with no active scenes, avoiding Adreno KGSL context exhaustion after repeated opens. Scene resources are still released on disposal, including the internal content-root node; textures and streams deferred by the last scene are destroyed after the next scene's grace frames, never with no renderer to count them. Disposed loaders reject late resource creation. Passing either custom creator keeps a separate owned engine with the existing backend-idle teardown.
