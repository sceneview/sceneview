- **Repository:** the demo apps' 3D models and HDR environments (Android, TV, iOS) and the website's platform models move out of git into the `assets-v1` GitHub Release, listed with their sha256 in `assets/manifest.json`. `bash tools/fetch-assets.sh` downloads them once into a shared cache and puts them back in place; the Android, TV and iOS demo builds, the website deploy and every CI workflow that builds them run it on their own. A checkout shrinks by about 544 MiB. The store apps and the website ship byte-identical files.
