- **Repository:** the demo apps' 3D models and HDR environments (Android, TV, iOS) and the website's platform models move out of git into the `assets-v1` GitHub Release, listed with their sha256 in `assets/manifest.json`. `bash tools/fetch-assets.sh` downloads them once into a shared cache and puts them back in place; the Android, TV and iOS demo builds, the website deploy and every CI workflow that builds them run it on their own. A checkout shrinks by about 544 MiB. The store apps and the website ship byte-identical files. Building the demos or the site now needs bash, python3 and curl (Windows: WSL), and a model that is in a managed folder but not registered in the manifest fails the build instead of shipping from one machine only. The CREDITS drift check (`generate-credits.py --check`), which had run in no workflow since #3244, is back in CI.
