- **`ARPlacementDemo` bottom-sheet settings populated ([#1883](https://github.com/sceneview/sceneview/issues/1883)).** The previously empty panel above the Reset button now exposes four meaningful controls: (a) per-bundled-model picker chips (Damaged Helmet / Fox / Lantern / Toy Car / Shiba) alongside the existing streamed Sketchfab slugs and the bundled-cycle chip, so the user can lock placement to a single GLB instead of rotating through the cycle; (b) "Clear all placed" button (renamed from "Clear All" for parity with the action vocabulary used elsewhere in the demo); (c) "Snap to plane" toggle (default ON) that gates both the tap-to-place rule and the reticle's hit-test predicate — turning it off opts placement into instant placement + depth points + feature points so the user can drop models on textured surfaces ARCore hasn't grown a plane on yet; (d) "Show reticle" toggle (default ON) that hides the cyan placement disc and falls placement back to the legacy tap-coordinate hit test — debug aid for capture-only screenshots and for verifying the fallback path. The scaffold's "Reset" header button now also clears placed models + restores every toggle and picker selection to defaults, so the demo can be handed off to a new tester with one tap.
