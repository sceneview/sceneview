- **World ↔ local quaternion conversions no longer run a Mat4 polar decomposition on every call ([#2267](https://github.com/sceneview/sceneview/issues/2267)).** Setting `Node.worldQuaternion` / `Node.worldRotation` (and the underlying `getLocalQuaternion` / `getWorldQuaternion`) used to decompose a 4×4 matrix into its rotation component (`worldToLocal.quaternion`) every time. A rotation-only conversion never needs the matrix: it is just `inverse(parentWorldQuaternion) * worldQuaternion`. New direct-quaternion overloads `worldToLocalQuaternion(parentWorldQuaternion, worldQuaternion)` / `localToWorldQuaternion(parentWorldQuaternion, localQuaternion)` (and the Euler `worldToLocalRotation` / `localToWorldRotation` variants) skip the decomposition entirely, reusing the world-space quaternion cache landed in [#2264](https://github.com/sceneview/sceneview/issues/2264). The legacy `Transform`-taking overloads are kept for source compatibility but `@Deprecated`. Part of the hot-path allocation audit ([#2263](https://github.com/sceneview/sceneview/issues/2263)).
