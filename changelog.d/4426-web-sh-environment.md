- **Web: `setEnvironmentSH()` and the fallback lighting apply ([#4426](https://github.com/sceneview/sceneview/pull/4426)).** In `sceneview.js`, both built their light with a Filament.js method that does not exist, and the error was swallowed: a viewer that could not download its KTX environment rendered with no indirect light at all, and `setEnvironmentSH()` did nothing. They now call `irradianceSh` with 3 bands (27 floats) and add a small reflections cubemap computed from the same harmonics, so metals are lit too. The fallback uses the harmonics of the default environment at the viewer's `iblIntensity`: a model keeps about the same brightness when the KTX is unreachable. `setEnvironmentSH()` rejects an array that is not 27 coefficients with a warning and keeps the current environment. Pages whose KTX loads render exactly as before; the Warm, Cool and Dramatic presets of the playground and of the web demo, which had no effect, now relight the model.
