- **Rigged models get bounds that match what is drawn** (#4949). gltfio sizes a skinned mesh from its accessors' unskinned min / max, so a character exported in centimetres under an armature scaled by 0.01 (the usual Mixamo or Blender export) measured about 189 m instead of 1.89 m, and auto-scale, framing and collision followed. `ModelLoader` now computes each skinned model's rest-pose box from its joints at load time, and `ModelNode.boundingBox`, `worldBoundingBox`, `scaleToUnitCube`, the collision shape and `ModelSnapshot` framing use it. Read it yourself through the new `Model.restPoseBoundingBox` (it falls back to gltfio's box when a model has no skin). Models without skins are unchanged; a `.gltf` with embedded `data:` buffers keeps gltfio's box. Apps no longer need `FilamentInstance.recomputeBoundingBoxes()`, which gltfio's Java API does not expose and which needs the source data SceneView releases once a model is loaded.
