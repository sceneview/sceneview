- **Demo — Museum & Space follow-ups.** Leaving an HD scan for a bundled model no longer shows a black stage while the next model loads; a paused animation stays paused when the HD file replaces its stand-in; an opened file or a Surprise pick no longer switches the lighting to Studio; one failed model download no longer marks the whole HD pack "Failed" in About; picker card titles wrap to two lines ("Apollo 11 Command Module"); after "Open with SceneView", picking another model retitles the screen and sends that model to AR. (#4171)
- **`ModelNode` — an animated model no longer vanishes when another model is destroyed after it was added.** gltfio's animator re-sorts Filament's TransformManager on every frame it plays, which reindexed the node's cached transform handle; its transform then went to one of the model's own meshes and a skinned model rendered as nothing. The first animated frame after a destroy or a reparent now invalidates those handles. (#4171)
