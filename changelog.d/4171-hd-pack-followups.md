- **Demo — Museum & Space follow-ups.** Leaving an HD scan for a bundled model no longer shows a black stage while the next model loads; a paused animation stays paused when the HD file replaces its stand-in; an opened file or a Surprise pick no longer switches the lighting to Studio; one failed model download no longer marks the whole HD pack "Failed" in About; picker card titles wrap to two lines ("Apollo 11 Command Module"); after "Open with SceneView", picking another model retitles the screen and sends that model to AR. (#4171)
- **`ModelNode` — an animated model no longer vanishes when another model is destroyed after it was added.** Every gltfio `Animator.applyAnimation` commits a TransformManager transaction, and a commit re-sorts the packed hierarchy — but only when a destroy or a reparent has broken its order, not on every frame. That re-sort reindexed the node's cached transform handle; its transform then went to one of the model's own meshes and a skinned model rendered as nothing. Until the order is repaired, nodes now resolve their handles fresh instead of caching them, so a commit from anywhere — `ModelNode`, a direct `applyAnimation` or `applyCrossFade`, app code — is safe; the frame loop repairs the order once at the top of the next frame, and caching resumes. (#4171)
