- **Release: the documented way to republish `sceneview-mcp` between SDK releases works again ([#4410](https://github.com/sceneview/sceneview/pull/4410)).** The dispatch-only `mcp-publish.yml` workflow could no longer publish: npm accepts one trusted-publishing workflow per package, `sceneview-mcp`'s is `release.yml`, and the `NPM_TOKEN` fallback that workflow relied on is refused with `EOTP`. It is deleted. The MCP is republished by dispatching `release.yml` on `main` (`gh workflow run release.yml --ref main`): every publisher job skips a version already on its registry, and the GitHub Release and API-docs deploy only run on a tag, so only the MCP ships. Documented above the `publish-mcp` job and in `mcp/CONTRIBUTING.md`.
