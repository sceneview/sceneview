- **`generate_world` MCP tool — World Labs Marble worlds as Gaussian splats ([#3751](https://github.com/sceneview/sceneview/pull/3751)).** `sceneview-mcp` can now generate a navigable 3D world from a text prompt, an image (or 360° panorama) or a ≤30 s video via World Labs' World API (BYOK, `WORLDLABS_API_KEY`, local `npx sceneview-mcp` only), and returns `.spz` splats in 100k / 500k / full tiers, a collider GLB and a panorama with ready-to-paste `SplatNode` / `addSplatNode` snippets, the OpenCV → Filament rotation and an `operationId` to resume a timed-out generation without paying twice. The Android and web skills and `llms.txt` gain a matching "load a World Labs world" recipe, and `agents/REGISTRY.md` documents shipping the skill inside an ADK for Kotlin agent.
