- **`generate_world` MCP tool — World Labs Marble worlds as Gaussian splats ([#3751](https://github.com/sceneview/sceneview/pull/3751)).** `sceneview-mcp` can now generate a navigable 3D world from a text prompt, an image (or 360° panorama) or a ≤30 s video via World Labs' World API (BYOK, `WORLDLABS_API_KEY`, local `npx sceneview-mcp` only), and returns `.spz` splats in 100k / 500k / full tiers, a collider GLB and a panorama with ready-to-paste `SplatNode` / `addSplatNode` snippets, the OpenCV → Filament rotation and an `operationId` to resume a timed-out generation without paying twice. The Android and web skills and `llms.txt` gain a matching "load a World Labs world" recipe, and `agents/REGISTRY.md` documents shipping the skill inside an ADK for Kotlin agent.
- **The demo apps hand "Generate a 3D world" off to AR Model Viewer ([#3751](https://github.com/sceneview/sceneview/pull/3751)).** A full-width card closes the Android and iOS Showcase grids next to "Browse online models": it says what the feature does (a video, a photo or a sentence becomes a walkable Gaussian-splat world, generated by World Labs) and that each world spends paid credits, then leaves the app — on Android through an `armodelviewer://generate-world` deep link when AR Model Viewer is installed, its launcher when it is installed but predates the link, or the Play Store listing with a `utm_source=sceneview-demo` referrer otherwise; on iOS, where AR Model Viewer has no App Store listing yet, to the AI-development docs page, flipping to the store the day an id is set. Neither app holds a World Labs key, so nothing in SceneView itself can spend credits.
