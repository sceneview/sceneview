- **`ReticleNode` library-level placement reticle ([#1882](https://github.com/sceneview/sceneview/issues/1882)).** New `arsceneview` node + `ARSceneScope.ReticleNode { ... }` Composable for the "tap to place" UX every AR placement demo previously had to reinvent. Continuously hit-tests at a fixed screen-space coordinate, auto-hides when the ray misses every trackable (so the visible marker doesn't ghost on a stale pose), and surfaces every hit-result change via `onHitResultChanged` — callers drive an "aim at a surface" hint and capture the last-known hit on tap-to-place without attaching a duplicate hit test in `onSessionUpdated`. Visual marker is left to the caller as a child node so the reticle stays material/style-agnostic. Wired into `ARPlacementDemo` (Pixel 9 QA): the placed model now lands exactly under the on-screen reticle. Documented in `llms.txt` (and the docs mirror) + `sceneview-mcp` bundle.
