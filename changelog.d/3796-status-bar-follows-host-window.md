- **Fixed invisible status-bar icons over a dark 3D scene while a bottom sheet is open, light theme (Model Viewer's Lighting and Settings sheets, [#3796](https://github.com/sceneview/sceneview/issues/3796)).** `ModalBottomSheet` opens in its own dialog window, so it derived the status-bar icon appearance from its own (light) theme rather than from what is actually behind the status bar — every demo viewport is a full-bleed dark 3D/AR stage in both themes. In the light theme this requested dark icons, which then sat on the still-dark scene and disappeared. `DemoModalBottomSheet` now mirrors the host Activity window's own status-bar appearance flag onto the dialog instead of recomputing it from the sheet's theme; the navigation bar, which does sit directly behind the sheet's own themed surface, keeps following the sheet's darkness.
