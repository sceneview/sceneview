- **Android demo: the Debug Overlay stress test runs to its end ([#4479](https://github.com/sceneview/sceneview/issues/4479)).** "Start stress test" stopped at 16 to 39 spheres with "Stress test stopped at the device limit": the spawn loop restarts on every new target, the ramp sets one every 50 ms, and the loop reported its own restart as a failed spawn. It no longer does. The ramp now goes from 1 to 1,000 spheres instead of 2,000, because 2,000 never fitted: on a 192 MB Java heap each 24×24 sphere holds about 115 KB, the heap filled near 1,450 spheres and the run stalled near 1,590 or ran out of memory. 1,000 spheres settle near 130 MB and the ramp stays between 47 and 60 fps on the QA emulator. The spawn rhythm is unchanged — the memory is held by the spheres, not by how fast they arrive.
