- `CI Gate` no longer passes green when a check run it gates disappears from a single Checks API read. The gate used to take every decision — what is still pending, whether the core-check guard is armed, and the final pass/fail — from one instant's response; while GitHub rebuilds a run attempt an entire check suite can be missing from that response. On [#3015](https://github.com/sceneview/sceneview/pull/3015) that window landed on the last poll and the single required check for branch protection went green over a `Compile KMP core` that had concluded `cancelled`. A check observed once for a head SHA is now carried across polls and treated as pending until it comes back with a fresh conclusion, or the gate times out red ([#3018](https://github.com/sceneview/sceneview/issues/3018)).
