- **`SceneRecorder` videos with an overlay record twice as many frames ([#5060](https://github.com/sceneview/sceneview/pull/5060)).** The overlay compositor waited on the CPU for each mirrored frame's GPU fence while holding a lock that Filament's render thread also needs. It now composites the scene and the overlay in one OpenGL ES pass, and the GPU does the waiting. On a Pixel 4a, a 1080p recording goes from about 10 fps to 20 fps, and the preview frame rate does not change. The ImageReader compositor stays as a fallback for devices where EGL cannot be set up on the encoder surface. Videos now draw the `CaptureOverlay` on a software canvas, as photos already did, so an overlay must not draw `HARDWARE` bitmaps.
