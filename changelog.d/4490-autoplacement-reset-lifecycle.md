- **Place the same model again after Reset in automatic placement and Cloud Anchors ([#4490](https://github.com/sceneview/sceneview/issues/4490)).** Release the automatic placement's anchor on Reset even while camera frames are paused. Disposing model nodes now preserves the caller-owned glTF instance, its authored hierarchy and any replacement geometry until the asset is destroyed, so a new placement can reuse it without reloading the model.
