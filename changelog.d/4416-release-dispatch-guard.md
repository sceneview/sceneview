- **Release: a manual dispatch of `release.yml` only publishes from `main` or a `v*` tag, and can be limited to `sceneview-mcp` ([#4416](https://github.com/sceneview/sceneview/issues/4416)).** A dispatch on any other ref used to run every publisher, so a branch carrying an unpublished `mcp/package.json` version would have shipped it with valid provenance; the guard job every publisher needs is now skipped there. `gh workflow run release.yml --ref main -f mcp_only=true` republishes the MCP and skips Maven Central, `sceneview-web`, React Native, pub.dev, the SPM check, the API docs and the GitHub Release, instead of relying on each of them finding its version already published. The "already published?" probes fail closed: a registry error, a rate limit or an unreadable answer now fails the step instead of reading as "not published", and an unreadable `sceneview-web/package.json` fails instead of falling back to `0.0.0`.
