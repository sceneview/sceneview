- **One Android model entry point across mesh formats ([#3489](https://github.com/sceneview/sceneview/issues/3489)).** Shared `ModelFormat` sniffing and `ModelConverter` dispatch GLB, glTF, 3MF, STL, OBJ and PLY meshes; `ModelUnit` overrides unitless mesh sizes through `ModelLoader` and Compose (`rememberModelInstance(modelLoader, location, unit = …)` behaves like the other `rememberModelInstance` overloads: `null` and a log on failure). Unsupported inputs (STEP, FBX, USDZ, splat PLY/SPZ) fail with `UnsupportedModelFormat` before native parsing. **Behaviour change:** for such a file, the `suspend` `ModelLoader.loadModel` / `loadModelInstance` / `loadInstancedModel` and the synchronous `createModel*` now throw `UnsupportedModelFormat`, where they used to return `null` (an empty list for `loadInstancedModel`; the synchronous calls threw a generic parse error); the `*Async` callbacks and `rememberModelInstance` still give `null`, logged. The new "Open any 3D file" reference lists units, materials and real-size loading; splats retain their dedicated renderer.
