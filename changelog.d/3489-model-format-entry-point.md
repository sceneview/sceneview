- **One Android model entry point across mesh formats ([#3489](https://github.com/sceneview/sceneview/issues/3489)).** Shared `ModelFormat` sniffing and `ModelConverter` dispatch GLB, glTF, 3MF, STL, OBJ and PLY meshes; `ModelUnit` overrides unitless mesh sizes through `ModelLoader` and Compose (`rememberModelInstance(modelLoader, location, unit = …)` behaves like the other `rememberModelInstance` overloads: `null` and a log on failure). Unsupported inputs (STEP, FBX, USDZ, splat PLY/SPZ) are refused before native parsing, without a second copy of the file in memory: the synchronous `createModel*` and `awaitModelInstance` (so `rememberModelLoadState`) throw `UnsupportedModelFormat`, while the `suspend` `loadModel` / `loadModelInstance` / `loadInstancedModel`, the `*Async` callbacks and `rememberModelInstance` keep returning `null` (an empty list), logged — also for a file a mesh converter cannot parse, such as an HTML error page saved as `.stl`. The new "Open any 3D file" reference lists units, materials and real-size loading; splats retain their dedicated renderer.
