- **Demo app (debug builds):** a debug build of the Android demo is now its own app, installed next to the Play Store one instead of replacing it: application id `io.github.sceneview.demo.qa`, version suffixed `-qa`, launcher label "SV QA" and the SceneView icon with an amber QA badge (themed icon included). QA scripts, Maestro flows and instrumentation tests now target that id. The debug APK attached to GitHub Releases is unchanged — still `io.github.sceneview.demo`, "SceneView" — because `build-apks.yml` builds it with the new `-PdemoPlainDebug=true` Gradle property.
