- **The playground's iOS snippets now compile against SceneViewSwift ([#3192](https://github.com/sceneview/sceneview/issues/3192)).** All fourteen used APIs that do not exist (`ModelNode("…")`, `DirectionalLightNode`, `.scaleToFit`, `.onTapAR`, `.onFaceUpdate`). They now load models with `ModelNode.load`, light with `LightNode.directional`, place AR content with `onTapOnPlane` and `AnchorNode.world`, and the "copy prompt" iOS block says the same thing. `sceneview.js` reported 4.18.0 in its header and in `SceneView.version`; both now read the current version and `sync-versions.sh` keeps them there. The structured-data FAQ no longer advertises the removed `list_node_types` MCP tool, and the GPT system prompt's version block reads the current release and Kotlin 2.4.20.
