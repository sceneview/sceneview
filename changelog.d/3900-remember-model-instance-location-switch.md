- **`rememberModelInstance` documents what it returns while a location switch is loading ([#3900](https://github.com/sceneview/sceneview/issues/3900)).** The `@return` of both overloads said "`null` while loading", but `produceState` retains its last value across key changes, so on a switch the *previous* `ModelInstance` is returned until the new one is ready and a `null`-based loading state never fires. The KDoc, `llms.txt` and the nodes doc now say so, and point to the `key(location) { … }` workaround used by the Animation & Physics sample. No behaviour change.
