- **Android KTX environments release their GPU cubemaps ([#4358](https://github.com/sceneview/sceneview/issues/4358)).** `createEnvironment(environmentLoader)`, `EnvironmentLoader.createKTX1Environment` / `loadKTX1Environment` and `createAREnvironment` kept the `IndirectLight` and `Skybox` of Filament's KTX bundles and dropped the cubemap each one samples, so every rebuilt environment — a `rememberEnvironment` key change, a screen opened again — left one on the GPU (2 MB for the bundled neutral IBL) until the engine was destroyed. An `Environment` now owns those cubemaps, and `EnvironmentLoader.destroyEnvironment` and `Engine.safeDestroyEnvironment` both destroy them after the light and the skybox — the HDR cubemaps too, which only the loader released. Building an `IndirectLight` from a KTX bundle yourself: pass its cubemap to the new `createEnvironment(engine, …, textures = …)` overload — as the demo's AR Rerun replay, dollhouse and scan-model views now do, which rebuilt theirs on every theme change.
