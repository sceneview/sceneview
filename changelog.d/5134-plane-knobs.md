- **arsceneview: `sceneUnderstanding` no longer turns planes back on over `planeRenderer = false` ([#5134](https://github.com/sceneview/sceneview/issues/5134)).** Planes are now drawn only when `planeRenderer` and `SceneUnderstanding.planeVisualization` are both `true`, written once per recomposition. `ARSceneView(planeRenderer = false, sceneUnderstanding = SceneUnderstanding(occlusion = true))` keeps planes hidden, and `SceneUnderstanding.Minimal` / `.None` still hide them on their own. No API change. This reverses the 4.10 contract, where the grouped flags overrode `planeRenderer`: if you relied on `planeVisualization = true` or `SceneUnderstanding.Full` showing planes over `planeRenderer = false`, remove `planeRenderer = false` or drive `planeRenderer` instead.
