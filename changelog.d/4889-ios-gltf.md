- **glTF and GLB on iOS, macOS and visionOS ([#4889](https://github.com/sceneview/sceneview/pull/4889)).** `ModelNode.load("models/fox.glb")` now opens glTF 2.0 with SceneViewSwift's own importer, with no third-party dependency. It works through the same call as USDZ, with the URL and remote variants too. The importer reads GLB, `.gltf` with its `.bin` and images next to it, and `data:` URIs. It brings in the node hierarchy, metallic-roughness materials with their textures, alpha modes, unlit, texture transforms, skins and animations; the animations play through the existing `playAnimation(at:)` and `playAllAnimations()`. Parsing and image decoding run off the main thread. Morph targets show the base shape. A file that requires Draco, meshopt or any other extension SceneView does not implement throws `ModelLoadingError.unsupportedRequiredExtension`, which names the extension. The iOS demo opens `.glb` and `.gltf` files shared to it.
