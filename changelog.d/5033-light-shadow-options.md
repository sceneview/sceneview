- Directional shadows no longer disappear when a light is given shadow options. On Filament 1.77, `LightManager.ShadowOptions()` starts from all-zero values and the bindings store its `transform` in the wrong order (google/filament#10565), so `LightNode(type) { shadowOptions(ShadowOptions().apply { … }) }` silently lost its shadow. `LightNode` now writes those options itself, keeping Filament's defaults for every field left alone. New `LightComponent.updateShadowOptions { … }` changes a light's shadow options after creation, starting from its current values.
