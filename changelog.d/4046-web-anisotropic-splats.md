<!-- category: Fixed -->
- **Web Gaussian splats render as oriented ellipses with the right colours ([#4046](https://github.com/sceneview/sceneview/issues/4046)).** `sceneview-web` now projects each splat's rotation and 3-axis scale to a screen-space ellipse with the same math as Android (pixel Jacobian, 0.3 px² low-pass, opacity-bounded extent), instead of a round billboard sized by the largest axis, and undoes the view's Filmic colour transform so a splat displays the colour it stores. A cloud above 2^24 splats is refused with the limit in the error (`onError` / `IllegalArgumentException`) before anything is allocated, instead of a generic fetch failure.
<!-- category: Performance -->
- **Web splat re-sorts upload one small texture instead of two ([#4046](https://github.com/sceneview/sceneview/issues/4046)).** Attributes are uploaded once in cloud order; a re-sort only rewrites the order texture, now 4 bytes per splat (0.94 MB instead of 7.5 MB for the 233 808-splat raccoon scan).
