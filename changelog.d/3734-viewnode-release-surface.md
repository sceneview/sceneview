- **`ViewNode.destroy()` now releases its `Surface`/`SurfaceTexture` ([#3734](https://github.com/sceneview/sceneview/issues/3734)).** They used to be leaked on every destroy — hosting a `Composable` or an Android `View` in a `ViewNode` and destroying it repeatedly (e.g. recomposition, a recycled list of 3D cards) built up native `Surface`/`SurfaceTexture` handles with nothing to reclaim them. The release now runs through the same frame-deferred queue as the `Texture`/`Stream` (#874), strictly after the `Stream` reading from them has actually been destroyed, so it can never free them out from under a still-live `Stream`.
