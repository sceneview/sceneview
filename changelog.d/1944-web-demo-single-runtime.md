- web-demo: removed the dead Kotlin/JS runtime so the demo has one runtime, not two. The shipped page (`samples/web-demo/index.html`) has always run on its inline JS over the CDN-hosted `sceneview.js`; the parallel `Main.kt` entry point built against `:sceneview-web` was compiled by CI but never loaded by the page, so contributor changes to it (e.g. the #1944 Spatial Audio wiring) were silently dead. `Main.kt`, the `:sceneview-web` dependency, the Kotlin/JS Gradle module, and the webpack config are deleted; `index.html` moves up to `samples/web-demo/index.html` and the demo is now a plain static site (no build step). CI no longer compiles or webpacks a dead bundle.
