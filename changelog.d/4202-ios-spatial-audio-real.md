- **iOS demo: Spatial Audio gets quieter as the bell moves away from you ([#4202](https://github.com/sceneview/sceneview/pull/4202)).** The volume was computed from the bell's distance to the centre of the scene, which never changes on its orbit, so the Inverse / Linear picker did nothing. It now follows the distance between the bell and the camera, like Android, with the same legend, distance readout and volume meter.
- **SceneViewSwift: `SpatialAudioNode.updateGain(forDistance:)` is the only distance law ([#4202](https://github.com/sceneview/sceneview/pull/4202)).** It turns RealityKit's built-in rolloff off so the chosen `AudioFalloff` curve is not applied twice, returns the linear gain it pushed, and `playbackGainDecibels` reads the playback gain back.
