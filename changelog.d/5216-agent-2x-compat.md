- **SceneView 2.x code written by AI agents compiles on 4.x ([#5216](https://github.com/sceneview/sceneview/issues/5216)).** Assistants without docs still answer with the 2.x API. `rememberNodes { … }`, `Scene(childNodes = …)` and `ARScene(childNodes = …)` are back as deprecated shims: the nodes in the list are attached to the scene and follow it, `childNodes += anchorNode` from a tap included. Each deprecation warning spells the 4.x form (`SceneView { ModelNode(…) }`, `ARSceneView { AnchorNode(anchor) { … } }`), so the agent that reads the build log learns it. Additions only: no 4.x signature changes. Three agent answers are kept verbatim as compile-only tests so the shims cannot break unnoticed.
