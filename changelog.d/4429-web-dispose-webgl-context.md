- **Web: `dispose()` hands the WebGL context back to the browser ([#4429](https://github.com/sceneview/sceneview/pull/4429)).** A disposed viewer kept its WebGL context alive, and Chromium force-loses the least recently used context past 16 per page: after some 16 create/dispose cycles, an idle viewer still on the page went black. `dispose()` now loses the canvas's context once the engine is destroyed (the canvas fires `webglcontextlost`), and `SceneView.create()` on that canvas restores it before it builds the new engine. Safari keeps counting a lost context against its own cap, so it still evicts past 16.
