- **Load progress and clear errors for large GLBs ([#4823](https://github.com/sceneview/sceneview/pull/4823)).** `ModelLoader.awaitModelInstance` returns once every texture is final and reports `Reading`, `Creating` and `Textures` progress on the main thread; `rememberModelLoadState` exposes the same load as `Loading(progress)`, `Ready` or `Failed` in Compose. A model whose `extensionsRequired` names an extension gltfio cannot load, such as `EXT_texture_avif` or `KHR_meshopt_compression`, now fails with `UnsupportedGltfExtensionException` before any Filament call instead of rendering untextured without a word; `ModelLoader.SUPPORTED_GLTF_EXTENSIONS` lists what works. Files are read into one array of their size, which halves the Java heap peak of a load (108 to 54 MB for a 53 MB model).
