- **perf(SceneViewSwift): `applyCamera()` per-frame diff-guard ([#2331](https://github.com/sceneview/sceneview/issues/2331), audit I27).** `applyCamera()` ran from `RealityView.update:` on every SwiftUI body re-eval (light-slot change, framing tick, skybox load, parent re-render) and from the ~60 Hz auto-rotate task, re-writing the root entity orientation/scale/position plus `perspCamera.look(at:from:)` / position / orientation and recomputing the orbit trig **even when the camera state was unchanged** — only the FOV write self-guarded. It now caches the exact camera inputs it last applied (`mode`/`target`/`azimuth`/`elevation`/`orbitRadius`/`fov`/`firstPersonEye`) and skips the per-mode entity writes when they are identical, mirroring the existing light-slot diff-write cache. Behaviour is unchanged (the same writes still land whenever any input moves); the static-camera frames just stop churning RealityKit's `Transform`/camera components. Completes #2331 (the Rerun/SceneObserver half shipped in #2372).
