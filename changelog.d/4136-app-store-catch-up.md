- **CI (App Store):** the latest release now reaches Apple on its own. A new `app-store-catch-up.yml` probes App Store Connect every 3 hours from an ubuntu runner and submits the latest GitHub release as soon as no other iOS version is in review. It reuses that release's TestFlight build, and only dispatches a macOS rebuild when no build exists. A release that has to wait behind another version in review now ends green with a notice instead of a red run. An opt-in `supersede` dispatch input withdraws an older version from review so the latest release can replace it.
