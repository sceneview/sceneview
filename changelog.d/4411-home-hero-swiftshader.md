- **The Android demo no longer aborts at launch on GPU-less virtual devices ([#4411](https://github.com/sceneview/sceneview/issues/4411)).** On x86_64 virtual devices that render with Android 11's own SwiftShader GLES library, the home hero took the process down inside Filament about a second after launch, on every start. The demo now reads the GL implementation before it creates an engine and, on that renderer, shows a still of the hero flight instead of rendering it. Every other device, the Android Emulator included, keeps the live flight. New in the library for the same check in your own app: `OpenGL.queryRenderer()` returns the device's `GL_VENDOR` / `GL_RENDERER` / `GL_VERSION` as a `GlRenderer` without creating an engine, and `GlRenderer.isLegacySwiftShader` names that one renderer.
