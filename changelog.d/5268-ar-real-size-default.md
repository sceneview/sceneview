- **`AutoPlacementModel` places the model at its real size by default ([#5268](https://github.com/sceneview/sceneview/pull/5268)).** The asset keeps its authored metres, as in AR Quick Look and Scene Viewer: a 1.8 m figure stands 1.8 m tall. Until 4.72 it was fitted into a 0.3 m preview. A model whose longest authored side exceeds 10 m (a file authored in centimetres) first shows fitted into 1 m and does not report `isAtRealWorldSize`. This also applies to an explicit `scaleToUnits = null`, which 4.72 documented as the "actual size" switch; `size = PlacementSize.RealWorld` keeps trusting the authored metres. To keep the old size, pass `scaleToUnits = 0.3f` (or `size = PlacementSize.FitInto(0.3f)`). The binary API is unchanged, and apps built against 4.72 get the new default without recompiling: the default is evaluated inside the library.
