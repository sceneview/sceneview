- **`NodeEditingOverlay`: TalkBack hears the rotation and scale badges in steps, not every degree ([#5139](https://github.com/sceneview/sceneview/issues/5139)).** While the gesture lasts, the badges' polite live-region description moves in 15° and 10 % steps, with a 2° / 2 % hysteresis so a value held on a step or eased off a scale limit does not flip. The visible text stays live. When the twist or pinch ends, the exact result is announced once. The "Rotation … degrees" and "Scale … percent" descriptions are string resources (`sceneview_editing_rotation_description`, `sceneview_editing_scale_description`) that apps can override to localise them.
- **`NodeEditingOverlay`: a model whose bounds are not ready yet no longer walks its glTF nodes every frame ([#5139](https://github.com/sceneview/sceneview/issues/5139)).** For a `ModelNode` with an empty rest-pose box, the overlay skips the model's own glTF nodes, which cost one native read per renderable per frame from possibly stale animated transforms. It still uses the children the app attached, so a mesh-less glTF used as a container keeps its ring. With nothing attached, the model gets the small placeholder ring.
