- **Demo app: the model viewer draws models that set their alpha cutoff to 1.0 ([#4103](https://github.com/sceneview/sceneview/issues/4103)).** The Fantasy Butterfly used to open on an empty stage. Its material asks to show only fully opaque pixels (`alphaCutoff` 1.0), and Filament drew none at that value. The viewer now lowers such a cutoff by one 8-bit step, so the fully opaque pixels are drawn as the file intends. The Credits sheet groups the former Scene Gallery models under "Model Viewer (Surprise me)". The bundled `sunset_2k.hdr` is credited as "Seascape", which is what it shows.
