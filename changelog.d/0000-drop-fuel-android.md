- **Android: `sceneview` no longer pulls in `kotlin-android-extensions-runtime` ([#PR](https://github.com/sceneview/sceneview/pull/PR)).** The `fuel-android` artifact, and with it `org.jetbrains.kotlin:kotlin-android-extensions-runtime:1.4.10`, is gone from the dependencies of `sceneview`, so also from `arsceneview` and `sceneview-compose`. Apps that excluded it by hand can drop the exclusion. `FileLoader` still downloads `http`/`https` models with Fuel 2.3.1 (`fuel` and `fuel-coroutines`), with the same timeouts, headers and errors, and `FileLoader.fuelManager` is unchanged. `fuel-android` only made Fuel's asynchronous `response { }` callbacks run on the main thread, and `FileLoader` does not use them. If your own code makes asynchronous Fuel calls through `FileLoader.fuelManager` and expects those callbacks on the main thread, declare `com.github.kittinunf.fuel:fuel-android:2.3.1` in your app.
- **Docs: the README, the quickstart and `llms.txt` say where to find the latest release ([#PR](https://github.com/sceneview/sceneview/pull/PR)).** The search.maven.org index is stale and still shows an old 2.x release as the latest, so it looked as if SceneView had stopped. The three places now point to Maven Central and to `maven-metadata.xml` instead.
