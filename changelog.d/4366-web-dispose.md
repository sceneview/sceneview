- **Web: `dispose()` frees the viewer's engine instead of leaking it ([#4366](https://github.com/sceneview/sceneview/issues/4366)).** In `sceneview.js`, `dispose()` now destroys every glTF asset, texture, light, environment and material before the Filament engine, so the engine really shuts down: 20 viewers created and disposed in a row grow the WASM heap by about 15 MB each instead of 45 MB, and the page no longer runs out of memory. Calling `dispose()` twice is a no-op, a model or environment still downloading is cancelled and its promise rejects with an `AbortError`, and replacing a model with `loadModel()` frees the previous one. The remaining 15 MB per viewer is Filament's own material archive, which its JavaScript API gives no way to release.
