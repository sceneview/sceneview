- **The public gateway pages advertised five hardcoded tool counts and every one of them had drifted ([#3192](https://github.com/sceneview/sceneview/issues/3192)).** The landing page's stat cards read 27 free / 27 Pro / 4 packages against a real 29 / 38 / 5; `/docs` opened on "the 27 free tools"; and two paragraphs of the same page disagreed with each other about the same npm package, one saying 28 and the other 29. The pages now read their numbers from `src/dashboard/counts.ts`, which derives all of them from the registry the gateway actually serves, so a stale number is no longer expressible.
- **The `/pricing` self-host FAQ promised "31 tools, no signup".** 31 is what the stdio package *declares*; three of those are the Pro generation helpers and refuse to run without a key, so the free-install promise overstated what a free install does — the one kind of stale number on that page that costs money rather than credibility. It now states the free count, with the declared total and the gated remainder spelled out.
- **The test that looked like it guarded this was pinning it.** `dashboard.test.ts` asserted `toContain("27 free tools")`: it stayed green while the registry moved to 29 and only turned red once the page was *corrected*. It reads the derived constant now. The hosted gateway and the local stdio package are kept as two distinct constants on purpose — they differ by the gateway-only `view_3d_model` widget tool, and flattening them to one number is what produced the 28-vs-29 contradiction.
- **Seven derived assertions added to `tool-count-claims.test.ts`, all mutation-verified** by restoring each original false number. Two of them exist because the first version of the guard let a deliberate mutant through: matching each count against the *set* of legitimate values accepted "29 free tools of the npm package" — real number, wrong surface, which is precisely the shipped bug — so each occurrence is now checked against the surface its own sentence names. The landing page needed its own case as well: it prints the label and the number in two sibling elements, so the prose assertions matched nothing there and would have passed vacuously over the three numbers that had been wrong the longest.
