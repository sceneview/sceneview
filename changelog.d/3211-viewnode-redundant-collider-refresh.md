- **A `ViewNode`'s hand-assigned `collisionShape` now survives a resize.** `ViewNode.updateGeometrySize()` ended with an unconditional `updateCollisionShape()`, added when the stale-collider fix was still scoped to that one call site ([#2845](https://github.com/sceneview/sceneview/issues/2845)). Being unconditional, it overwrote a collider the app had set by hand on every resize — and resurrected a pickable one on a node deliberately made unpickable with `collisionShape = null`. The refresh now lives in `RenderableNode.setGeometry` for every node type ([#3194](https://github.com/sceneview/sceneview/issues/3194)), so the explicit call is redundant: removing it restores the documented opt-out and drops a second AABB read per resize. `ViewNode`'s collider still tracks its quad, through the shared path.
