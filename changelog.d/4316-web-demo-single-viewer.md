- **`addLight()` no longer throws for point and spot lights in the web viewer ([#4316](https://github.com/sceneview/sceneview/issues/4316)).** `sceneview.js` called `Filament.mat4.translation()`, which the Filament.js binding does not have, on a light entity with no transform component. It now creates the component and sets a column-major translation. Lights added this way are tracked, so `removeNode()` removes and destroys them.
- **The web demo runs the same viewer as sceneview.dev ([#4316](https://github.com/sceneview/sceneview/issues/4316)).** `samples/web-demo` shipped its own copy of `sceneview.js`, stuck at 3.6. That copy is gone: the deployed `/web-demo/` route, the Playwright server and local runs all stage `website-static/js/sceneview.js`. The demo passes its relative IBL URL explicitly, and its "Remove Added Lights" and "Remove Added Text" buttons, which silently did nothing, now remove what was added.
- **Models authored in millimetres are no longer culled by the web viewer's far plane ([#4316](https://github.com/sceneview/sceneview/issues/4316)).** The far plane was a fixed 1000 units; it now follows the zoom-out limit of the framed model once that exceeds 1000, so the demo's Retro Piano renders. Nothing changes for a model framed closer than about 133 units.
