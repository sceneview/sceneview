<!-- category: Changed -->
- **Android now runs on Filament 1.77.3 ([#4930](https://github.com/sceneview/sceneview/pull/4930)).** Every Android material blob is recompiled for it (material version 77). `Scene.removeEntity`, `Engine.isValid()` and the SurfaceTexture `Stream.Builder.stream` were removed upstream: SceneView now uses `Scene.remove`, a new `Engine.isValid` extension and `StreamHelper.setStreamSource`. The web runtimes are unchanged.
  - **If your app calls Filament directly:** SceneView exposes Filament as an `api` dependency, and Filament 1.77 regenerated its Java bindings. Code that calls a removed Filament member no longer compiles, and a prebuilt library compiled against Filament 1.72 throws `NoSuchMethodError`. Some changes are silent: `LightManager.ShadowOptions()`, `Renderer.FrameRateOptions()` and `Renderer.DisplayInfo()` now start with every field at 0, so a light built with `shadowOptions(ShadowOptions())` loses its directional shadow (google/filament#10565, fixed in 1.79). Build the light with `castShadows(true)` and edit `lightManager.getShadowOptions(instance)` instead. `Box.getCenter()` and `getHalfExtent()` now return copies, so writing into them has no effect.
