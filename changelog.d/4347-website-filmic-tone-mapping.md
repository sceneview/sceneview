- **The website's model viewers tone-map with Filmic, like Android and the Kotlin/JS bundle ([#4347](https://github.com/sceneview/sceneview/issues/4347)).** The hand-written `website-static/js/sceneview.js` (site pages and `/web-demo/`) left its view on Filament's default ACES (legacy) curve. It now sets a Filmic `ColorGrading`, released with the viewer in `dispose()`: saturated colours keep more of their saturation and mid-tones are a little brighter. The background is no longer graded: the `backgroundColor` option and `setBackgroundColor(r, g, b, a)` now take the colour as displayed (sRGB 0–1, a hex byte / 255 — the contract `sceneview-web` already has), where they used to take linear values that ACES graded on the way to the screen. Every page of the site is restated so its background is the same pixel as before (default dark slate `#333C57`), except `view.html` and `open/`, which now show their `stage-background` design token instead of a darker grade of it. A page of your own that loads this script with explicit background values gets exactly those values on screen now — restate them if you had tuned them by eye. A transparent canvas is unchanged.
