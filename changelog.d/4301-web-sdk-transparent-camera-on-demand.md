- **The hand-written web viewer (`sceneview.js`) gains a transparent canvas, a camera API and render on demand ([#4301](https://github.com/sceneview/sceneview/pull/4301)).** `SceneView.create(canvas, { transparent: true })` clears to alpha 0 so the page shows behind the model. `getCameraOrbit()`, `setCameraOrbit({ angle, height, radius, target, fov })` and `frameModel({ fill })` replace poking private fields; the setters are chainable, and `frameModel({ fill: 0.8 })` keeps the model within 80 % of the view, in height and in width, at every angle of the orbit. `renderMode: 'onDemand'` (or `setRenderMode()`) stops drawing once nothing moves and wakes on input, camera calls, scene changes or `requestRender()`. It shares the existing off-screen gate, so an idle or off-screen viewer draws no frames, video quads included. `onFrame(callback)` runs after every drawn frame while the canvas is still readable, for reflections or thumbnails. The defaults are unchanged.
