- **`ARSceneView` no longer leaves a refused camera unexplained (Android)** — a system dialog dismissed with Back was reported as a permanent denial and sent to system settings, although asking again would have worked; the built-in card now says "Grant camera access" for it and keeps "Open settings" for a dialog Android has really stopped showing. A new `ARSceneView(onCameraPermissionStateChanged = …)` callback tells the host when the session is waiting for the camera, so its own loading chrome can step aside instead of covering the card — the black stage of #4452. `AutoPlacementScene` and `PlacementScene` use it themselves: their "Getting ready" coaching no longer sits on top of the card. A request whose answer never arrives ends on the card as well, a request Android cancels before showing it (another permission being asked, a rotation) is no longer counted as a refusal, a grant takes the card down on its own, and nothing — a late answer, a permission state the host kept — can start a session once the scene has left composition. Libraries compiled against the previous `ARSceneView` signature keep linking (#4452)
