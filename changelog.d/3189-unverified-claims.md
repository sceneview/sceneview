- **The Gemini Enterprise route is now labelled untested instead of stated as fact ([#3189](https://github.com/sceneview/sceneview/issues/3189)).** Four public surfaces — `README.md`, `mcp/README.md`, `docs/docs/ai-development.md` and `docs/docs/ai-context.md` — asserted that Gemini Enterprise accepts a Streamable HTTP MCP URL. That came from a secondary source; a verification pass found Google's own documentation URL 404s after redirect, so the claim is reported but unconfirmed. All four now say so plainly, and the plan's "write a Gemini Enterprise page" item is held rather than scheduled. ChatGPT's connector picker and Claude Desktop's remote MCP are unaffected — those take a URL and are documented as such. Shipping an unverified integration claim on the front of an AI-first SDK is the same defect this issue exists to remove, so it is corrected the same way: name the uncertainty rather than round it off.
