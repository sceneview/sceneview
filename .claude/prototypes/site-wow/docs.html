Quickstart

From an empty Android Studio project to a 3D model you can orbit with touch, in about ten minutes.

Prerequisites

  • Android Studio Ladybug (2024.2.1) or newer
  • A device or emulator on API 24 or higher
  • Some Kotlin and Jetpack Compose

  1. Add the dependency

    In your app module, add SceneView. One artifact covers 3D; AR lives in arsceneview.

    dependencies {
    implementation("io.github.sceneview:sceneview:4.51.0")
}
    # gradle/libs.versions.toml
[versions]
sceneview = "4.51.0"

[libraries]
sceneview = { module = "io.github.sceneview:sceneview", version.ref = "sceneview" }

# app/build.gradle.kts
implementation(libs.sceneview)

  2. Add a model

    Any glTF or GLB file works. This page uses the Sheen Chair from the Khronos sample assets (CC0): save SheenChair.glb as app/src/main/assets/models/sheen_chair.glb.

    Bringing your own file?

    USDZ, STL, OBJ, PLY and 3MF are converted on load. Model formats lists what each one keeps.

  3. Write the scene

    Replace MainActivity.kt. The scene is a composable; the model is a node inside it.

    MainActivity.kt 
    class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContent {
            val engine = rememberEngine()
            val modelLoader = rememberModelLoader(engine)

            SceneView(
                modifier = Modifier.fillMaxSize(),
                engine = engine,
                modelLoader = modelLoader,
                cameraManipulator = rememberCameraManipulator(),
            ) {
                rememberModelInstance(modelLoader, "models/sheen_chair.glb")
                    ?.let { instance ->
                        ModelNode(modelInstance = instance, scaleToUnits = 1.0f)
                    }
            }
        }
    }
}

    Imports omitted. The full file, with imports, is in the samples.

    What each call does

    CallRole
    rememberEngine()The Filament engine, one per screen.
    rememberModelLoader(engine)Loads glTF and GLB models from assets.
    rememberCameraManipulator()Orbit, pan and zoom gestures.
    SceneView { }The 3D viewport. Nodes go in the trailing lambda.
    rememberModelInstance(…)Loads the model asynchronously; null until it is ready.
    ModelNode(…)Places the model in the scene, scaled to one unit.

    Handle the loading state

    rememberModelInstance returns null while the file loads. Keep the ?.let; never force it with !!.

  4. Run it

    Press Run. After a short load, the chair appears: drag to orbit, pinch to zoom, two fingers to pan. That is a physically based viewer in about twenty lines.
