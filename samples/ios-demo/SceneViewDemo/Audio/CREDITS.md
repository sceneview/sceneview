## Regenerating the Sound stage loops

```bash
python3 assets/audio/make_sound_stage_loops.py
```

The script and its original synthesized recordings are dedicated to the public
domain under CC0 by the SceneView project. No samples or downloaded audio are used.
The Python 3 standard-library script writes both canonical and Android copies:
22 050 Hz, mono PCM 16-bit, peak −6.38 dBFS, 80 ms of silence at each end.
The independent lengths deliberately drift; the loops are not a synchronized score.
The iOS and web demos still use `bell.wav` only.

## Regenerating `bell.wav`

```bash
ffmpeg -y -f lavfi -i "sine=frequency=880:duration=0.6" \
       -af "afade=t=in:st=0:d=0.01,afade=t=out:st=0.05:d=0.55" \
       -ar 22050 -ac 1 -sample_fmt s16 \
       assets/audio/bell.wav
```

The output is deterministic across `ffmpeg` versions because the parameters
(sine generator, fade envelope, sample rate, mono channel, 16-bit PCM) are all
fully specified. A regenerated file should be byte-identical to the committed
one (≤ 1-2 bytes of header drift across major versions).
