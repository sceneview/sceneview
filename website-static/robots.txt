# Every crawler gets the same rules. The named groups below exist only because
# robots.txt group matching is winner-takes-all: a crawler that matches a named
# group ignores the `*` group entirely, so a named group that lists only
# `Allow: /` would silently hand that crawler the two paths everyone else is
# kept out of. Each named group therefore repeats the full rule set, and adding
# a crawler here grants it nothing the default group does not already grant.
# The list is alphabetical and favours no assistant.

User-agent: *
Allow: /
Allow: /llms.txt
Allow: /llms-full.txt
Disallow: /embed/
Disallow: /preview/
